# Sample Invoke-SCuBADiff Output

This folder holds sample output from [`Invoke-SCuBADiff`](../../../../docs/execution/diff.md), so you can see what the diff command produces without running it against your own tenant.

| File | Description |
|---|---|
| [DiffReport.html](DiffReport.html) | Self-contained HTML report. Unchanged rows are hidden by default. |
| [DiffResults.json](DiffResults.json) | Machine-readable diff, keyed by product, with a top-level `SchemaVersion`. |
| [DiffResults.csv](DiffResults.csv) | The same diff flattened to one row per policy. |

The three files were generated by `Invoke-SCuBADiff` and committed unmodified.

## Source files

The diff compares the sanitized ScubaGear v1.6.0 sample report (before) against the sanitized ScubaGear v2.0.0 sample report (after). This pair was chosen because it spans enough baseline changes to show a wide range of classifications. Both reports come from the same sanitized sample tenant, with an identical `TenantId` and `DomainName` in each file's `MetaData`. The diff output contains no tenant data that is not already in the sample reports.

The v1.6.0 before file is **not** shipped in this folder. The diff output already shows everything the before file contributes, and shipping it would add a second, outdated `ScubaResults_*.json` (about 1.4 MB) to the module. The before file remains available at the `v1.6.0` tag. See [Reproducing the diff](#reproducing-the-diff).

## How it was generated

- **ScubaGear:** 2.0.0, Diff module at commit `8c954fcd02995eb2649559c83d696a7b42ff464a`. For these inputs, the output matches the Diff module at tag `v2.0.0` except for the generation timestamp.
- **PowerShell:** Windows PowerShell 5.1
- **Diff generated:** `2026-11-05T16:24:25.088Z`

The v1.6.0 before file was extracted from the tag into the repository root, and the following command was run from the repository root:

```powershell
Invoke-SCuBADiff -BeforePath .\ScubaResults_v1.6.0.json -AfterPath .\PowerShell\ScubaGear\Sample-Reports\ScubaResults_df678ddd-66c2-4097.json -OutPath .\PowerShell\ScubaGear\Sample-Reports\DiffReports
```

The default output file names were used, and the extracted before file was deleted afterward.

## What the sample shows

A v1.6.0 to v2.0.0 upgrade covers most of the classifications you will see when you move to v2.0.0:

- **Migrated:** the Microsoft 365 Defender product is retired in v2.0.0, so `Defender` appears only in the before file. Its policies that have a single Security Suite replacement are aligned to that replacement (for example, `MS.DEFENDER.2.1v1 → MS.SECURITYSUITE.2.1v1`) and are also kept in the Defender section as `Migrated` rows. Three Exchange Online policies migrate the same way.
- **NewPolicy:** policies added in v2.0.0, including every Power BI policy (Power BI appears only in the after file), the Security Suite policies with no migrated source, and new Entra ID and Power Platform policies.
- **RemovedPolicy:** Defender, Exchange Online, and Teams policies retired in v2.0.0 that have no single Security Suite replacement, such as `MS.DEFENDER.1.1v1` through `MS.DEFENDER.1.5v1` and the `MS.EXO.14` and `MS.EXO.15` groups.
- **PolicyVersionUpdate:** policies whose version suffix changed between releases.
- **NewFail, NewPass, NewWarning, NewAutomatedCheck, and Unchanged:** result changes on policies present in both runs.

The sample contains 163 records. `Errored`, `NewIncorrectResult`, `NewManualCheck`, `NewOmission`, and `Other` do not occur in this pair. See [Diff Key Terminology](../../../../docs/execution/diff.md#diff-key-terminology) for every classification.

## Reproducing the diff

Download the v1.6.0 before file and diff it against the v2.0.0 sample report that ships with the module:

```powershell
$ModuleBase = (Get-Module -Name ScubaGear -ListAvailable | Sort-Object Version -Descending | Select-Object -First 1).ModuleBase
Invoke-WebRequest -Uri 'https://raw.githubusercontent.com/cisagov/ScubaGear/v1.6.0/PowerShell/ScubaGear/Sample-Reports/ScubaResults_0d275954-350e-4a22.json' -OutFile .\ScubaResults_v1.6.0.json
Invoke-SCuBADiff -BeforePath .\ScubaResults_v1.6.0.json -AfterPath (Join-Path $ModuleBase 'Sample-Reports\ScubaResults_df678ddd-66c2-4097.json') -OutPath .\SampleDiff
```

The downloaded file's SHA-256 is `bf79dba4c7c208df6a31aa61f3fca6e67a00af34769b74f38b9bb71d84a530d4`. From a repository clone, `git show v1.6.0:PowerShell/ScubaGear/Sample-Reports/ScubaResults_0d275954-350e-4a22.json > ScubaResults_v1.6.0.json` produces the same file in Git Bash or `cmd`. In Windows PowerShell 5.1, `>` re-encodes the output as UTF-16, so use the download instead.

The output should match this folder except for the generation timestamp.
